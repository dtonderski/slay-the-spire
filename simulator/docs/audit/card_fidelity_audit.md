# Card Fidelity Audit

Date: 2026-07-03

## Scope And Sources

This audit covers every local CardDefinition currently implemented in simulator/crates/sts_core/src/content/cards.rs (242 rows). Base and upgraded forms are listed separately whenever the simulator has separate content IDs or behavior. Repeated-upgrade Searing Blow is represented by Searing Blow+ plus per-card instance upgrade count.

Primary source facts come from the local decompiled Slay the Spire corpus under tmp/decompiled-sts/com/megacrit/cardcrawl/cards/**. Trusted online database facts come from [sts.gg /v1/cards](https://sts.gg/v1/cards), which states that it lists 374 cards and renders base/upgraded cost, type, and card text. Local simulator facts come from cards.rs, card_effects.rs, and transition.rs.

This is a fidelity audit, not a blanket parity claim. implemented_with_caveats means the card has local simulator behavior and no high-confidence printed-value mismatch was found in this pass, but exact action-manager ordering, random-pool identity, UI grid ordering, generated-card insertion position, or trace evidence may still be caveated by the existing M32A matrix. fixture_only rows are local simulator fixtures, not STS parity targets.

## Summary

- Local implemented card definitions audited: 242.
- Prior high-confidence printed definition mismatches fixed before this artifact: Twin Strike+, Dark Embrace, Pommel Strike+, Dual Wield/Dual Wield+, Searing Blow+, Infernal Blade exhaust keyword, and Sword Boomerang+.
- New high-confidence generic simulator mismatches found in this pass: none.
- Replay evidence after this documentation-only pass is recorded in STATUS.md; no simulator logic changed here.
