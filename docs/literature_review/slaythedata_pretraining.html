Run-level pretraining: what now works

We have working card/boss-relic extraction and supervised training code. Seed-based routing looks promising across all three acts—but full map equality and exact historical decision state remain unproven.

The map experiment

We generated maps from the logged seeds, without supplying the recorded routes to the generator, then checked whether each route was possible.

Strong seed/route association, not 99.9% certainty of exact maps. The logs don’t reveal unvisited nodes. Most routes also fit multiple coordinate paths, so we cannot simply choose one as the human’s path.

The code exports 1,494 hypothetical branch decisions from unique paths. These assume the generated map is correct, are clearly marked research-only, and are rejected by the supervised choice trainer.

Cards and relics

  • Cards: 14,943 usable conditional card-ranking examples extracted from 2,000 sampled runs. Picked/rejected cards are explicit; skip and Singing Bowl remain audited separately until eligibility is established.
  • Boss relics: 1,362 ranking examples. Missing picks are rejected. Historical deck/floor alignment is not invented.
  • Elite relics: acquisition history is retained, but those records don’t establish a mutually exclusive choice slate or declined offers. No fake preference labels.
  • Context: earlier logged choices/edits are available. Exact deck, potion inventory, counters and same-floor ordering are not yet reconstructed.

Does the learning pipeline work?

Yes. In a small fixed five-epoch pilot, the learned offer-only model matched 50.3% of validation choices, versus 33.1% uniform and 39.8% pick-frequency baselines. Adding partial logged history achieved 45.6%—it did not improve the overall result.

This is one optimization seed and 1,590 validation decisions. The test split was not evaluated. It demonstrates a working offline pipeline, not stronger play or a ready-to-load RL checkpoint.

Next useful work

Exact decision-time context and validated historical maps remain the main gaps before a meaningful warm-start of the existing A0 run actor. Follow-up experiments are tracked in the shared backlog, not a separate training roadmap.

Evidence, statistics and code

Historical build: 2020-07-30. Map audits use A0 complete normal 15-row act paths, excluding beta/special runs and logged Wing Boots. Card/relic extraction samples 1,000 ordinary-flag runs each at A0/A20. Inputs are read-only; no simulator mechanics or captured traces were changed.

Each act’s 9,999 seed-route permutations gave Monte Carlo association p = 0.0001. That is not the probability the map algorithm is wrong. With zero failures in 200 independent representative tests, the one-sided 99.9% upper failure-rate bound is 3.395%, for route compatibility only. Unvisited-map differences remain unidentifiable.
